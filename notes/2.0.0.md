## For agents

- Review provides the `review.drafts` service: its descriptor names `add_comment`, `propose_review` and `drop_run_comments`, and a `send` route that only a module server that proves who it is can use. No tool was added or removed.
- `add_comment` also takes `side` as `RIGHT` (the same as `new`) or `LEFT` (the same as `old`).
