- **Review is the review document.** Your verdict and summary at the top, then each point as a card with its code reference, severity, evidence, challenge and ruling, then the screenshots, logs and test output collected for it.
- **Code references open in Source and Diff.** Press a point's file and line and Source shows the file there while Diff shows the old and the new. Ask for a comment at a line in Source or Diff and a new point opens here, ready to write.
- **You keep what an agent wrote.** An agent's point is a draft until you press Keep or edit it; Send review posts your own points and the ones you kept, and nothing else.
- **Review skills.** /review-pass writes one careful review of the picked change, /review-point writes one well-sourced point where you are pointing, and /review-reply drafts a reply to each review thread on your own change for you to post.
- **A plain file behind it.** Each review is a Markdown file inside your project, with its evidence beside it, so you can read it and follow its history in git. Earlier drafts are moved over the first time you open them.
